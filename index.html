QA Sandbox (Mis proyectos)

Evidencia de mis estrategias de prueba, diseño de casos y documentación de defectos.

Web Testing

Auditoria de Funcionalidad: Flujo de Carrito de Compras

Diseño y ejecución de una matriz de pruebas funcionales y de regresión para validar el flujo crítico de un e-commerce. Seguimiento detallado para asegurar la correcta aplicación de descuentos en el checkout.

Artefactos: Plan de pruebas, Reporte de Bugs en Jira, Matriz de trazabilidad.
Mobile Testing

Pruebas Exploratorias y de Humo: App Móvil

Ejecución de pruebas específicas para dispositivos móviles, validando comportamientos ante interrupciones de red, cambios de orientación y adaptabilidad del diseño (Responsive) para garantizar una UX fluida.

Artefactos: Casos de uso, Checklist de Pruebas de Humo, Evidencia de logs.
API Testing

Validación de Endpoints con Postman: Módulo de autenticación

Pruebas funcionales a nivel de servicios backend para verificar las respuestas del servidor (códigos HTTP 200, 400, 401) en flujos de login. Análisis de payloads en formato JSON para asegurar la integridad de los datos.

Artefactos: Colección de Postman, Reporte de estado de Endpoints.
