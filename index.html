Web Testing

Auditoria de Funcionalidad: Flujo de Carrito de Compras

Simulación de pruebas de caja negra en un comercio electronico. Diseñe la matriz de casos de pruebay ejecuté pruebas de regresión para asegurar que los descuentos se aplicaran correctamente en el checkout.

Artefactos: Plan de pruebas, Reporte de Bugs en Jira, Matriz de conformidad.
Mobile Testing

Checklist de Humo: App Móvil en React Native

Pruebas específicas para dispositivos móviles simulando interrupciones de red (pérdida de Wi-Fi), cambios de orientación de pantalla y validación de diseño responsivo en diferentes resoluciones de pantalla.

Artefactos: Checklist de Pruebas de Humo, Capturas de logs de error.
API Testing

Validación de Endpoints con Postman: Módulo de autenticación

Pruebas funcionales a nivel de servicios (Backend) para verificar las respuestas del servidor (códigos HTTP 200, 400, 401) al enviar datos correctos en un formulario de login, analizando las respuestas en formato JSON.

Artefactos: Colección de Postman, Reporte de estado de Endpoints.
